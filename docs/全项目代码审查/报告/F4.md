**B1 死 CSS** —— **命中两处，已删**（证据见 §4）。删除后我对三个文件做了**全量 class 选择器 vs 标记引用**交叉扫描（脚本见下），结论：**三个文件已无死 CSS 类**。

```powershell
$base='D:\001Mine\009Code\project\security-bayes-situation-platform\frontend\src\views'
foreach ($f in @('Model\DatasetCenter.vue','Model\UserManagement.vue','Dataset\DatasetDetailView.vue')) {
  $raw=[System.IO.File]::ReadAllText((Join-Path $base $f))
  $i=$raw.IndexOf('<style'); $markup=$raw.Substring(0,$i); $styles=$raw.Substring($i)
  $c=[System.Collections.Generic.HashSet[string]]::new()
  foreach ($m in [regex]::Matches($styles,'\.([a-zA-Z][a-zA-Z0-9_-]*)')) {[void]$c.Add($m.Groups[1].Value)}
```
