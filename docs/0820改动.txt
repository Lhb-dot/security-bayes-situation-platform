六、数据集中心改为数据库真实数据（含航母场景显示修复）

问题：
- 数据集中心、字段预览、数据预览仍走 mockApi
- 航母甲板场景被前端占位拦截（“暂未接入数据集”），即使库里已有 3 个 carrier 数据集也不显示
- 后端预览接口返回的是数组行，前端表格按对象行列名渲染对不上

后端修改：
- backend/app/services/dataset_service.py
  - get_preview：ARFF 行转为“字段名 -> 值”的对象行，标签列可高亮
  - _to_dict：补充 name / field_count / data_format / record_count / referenced / enabled / scenario_code / scenario_name
  - _count_records：按文件 path+mtime 缓存样本数，列表接口避免重复扫盘

前端修改：
- frontend/src/api/datasetApi.ts
  - 对接后端真实结构到 Dataset / DatasetField / DataPreview / DatasetVersion
  - 列表默认按 logical_id 取最新版本；版本管理可取同逻辑集全部版本
  - 字段预览、数据预览、详情/停用/删除支持数字 id 与 logical_id
  - 上传/创建版本按后端契约传 file_path + fields_schema + label_field
- frontend/src/stores/datasetStore.ts
  - 数据源从 mockApi 切到 datasetApi（列表/字段/预览/版本）
- frontend/src/views/Model/DatasetCenter.vue
  - 改为调用真实 datasetApi + userStore
  - 删除航母甲板“暂未接入”占位，筛选航母时正常展示数据集表格
  - 上传/新版本表单增加 file_path（必须是仓库 data/ 下相对路径）
- frontend/src/views/Dataset/DatasetDetailView.vue
  - 标签列优先取字段角色，其次回退预览接口 label_field

结果：
- 数据集中心列表、字段预览、数据预览均读 PostgreSQL + 真实 ARFF
- 航母甲板 3 个数据集可见：carrier_feature2_biaoqian / carrier_feature2_lisan / carrier_paired_trail
