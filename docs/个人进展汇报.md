## 五、AI 训练页数据库化 + PMWNB 真实训练

### 5.1 背景

需求要求：业务场景/数据集/算法必须**从数据库渲染**，算法中的 PMWNB 必须**调用 Java 真实源码**（weka），其余四个算法算法组尚未交付、先用 mock 占位。

### 5.2 完成内容

**后端（真实训练链路）**：

- 调查 Java PMWNB 服务（`pmwnb-service.jar`，端口 12313）的 `/train` 接口契约：读取 ARFF、末列类别、自动离散化
- 编写 `training_executor.py`：
  - `execute_pmwnb_training()` —— 真实调用 Java `/train`，返回真实指标
  - `mock_training_metrics()` —— 其余四个算法的占位指标
  - 模型保存路径 `storage/models/pmwnb_mv{id}.model`
- `model_version_service.train_and_save()`：创建版本 → 训练 → 写入评估指标，成功转 DRAFT、失败转 FAILED
- 新增路由 `POST /api/v1/model-versions/train`
- 迁移 `20260808_000001`：5 个算法补齐 `display_name` + `param_schema`（PMWNB 空 schema；其余按离散方式/平滑/窗口等参数生成，前端据此动态渲染表单）

**前端（数据库渲染）**：

- 新增 `trainingApi.js`：`getScenarios / getDatasets / getAlgorithms / trainModel`
- 重写 `RiskAnalysis.vue`：场景/数据集/算法全部来自数据库；参数表单按算法 `param_schema` 动态生成；指标卡片缺失字段显示 `—` 不虚构；真实训练带 `java_pmwnb` 标记、mock 带 `mock` 标记
- `mockApi.ts`：登录 session 改存后端数字 ID，与后端 `X-User-Id`（数字 ID / 用户名双解析）对齐
