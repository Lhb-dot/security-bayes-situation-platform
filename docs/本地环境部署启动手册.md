# 本地环境部署启动手册

## 一、前端（Vue 3 + Vite）

### 环境要求
- **Node.js** >= 18.0.0（推荐 20 LTS）
- **npm** >= 9.0.0

### 安装与启动

```bash
cd frontend/

# 安装依赖（首次或 package.json 变更后）
npm install

# 开发模式启动（默认 http://localhost:5173）
npm run dev

# 生产构建
npm run build
```

### 跨域联调配置

开发模式下前端**同源**发请求：`frontend/src/utils/request.js:8` 的 `baseURL` 为
`import.meta.env.VITE_API_BASE_URL || ''`，`/api` 由 `frontend/vite.config.ts` 的
`server.proxy` 转发到 `http://localhost:12312`（保持 Cookie 第一方）。后端另有 CORS 中间件允许 `localhost:5173`。

如后端端口变更，需同时改 `frontend/vite.config.ts` 的 `server.proxy.target`；若要直连（不走代理），
设置环境变量 `VITE_API_BASE_URL`（不要再改 `request.js` 里的默认值）。

## 二、后端（Python FastAPI + Java PMWNB）

### 环境要求
- **Python** >= 3.10
- **Java** >= 17（用于 PMWNB 贝叶斯推理服务）
- **Windows** 10/11 或 Linux

### Python 虚拟环境搭建

```bash
cd backend/

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows Git Bash）
source venv/Scripts/activate

# 激活虚拟环境（Windows PowerShell）
.\venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt
```

### 配置环境变量

复制并编辑 `.env` 文件（位于 `backend/app/.env`）。`backend/app/config.py:29-39` 只读取下面 **5 个**键，
且是 `os.environ[...]` **直接索引**（缺失即 `KeyError`，后端 import 阶段就起不来），因此这 5 行必须存在（值可占位）：

```ini
# LLM（本项目 PMWNB 流程不实际调用大模型，占位即可）
LLM_BINDING_API_KEY=sk-placeholder
LLM_BINDING_HOST=http://127.0.0.1:8000
LLM_MODEL=placeholder-model
MAX_TOKENS=2048
MAX_ASYNC=4

# 数据库（PostgreSQL）——Docker 默认实例可整行省略，db.py 自带默认连接串
# DATABASE_URL=postgresql+psycopg2://<user>:<password>@<host>:<port>/<dbname>
```

> ⚠️ 以下键**已不再被任何代码读取**，写进 `.env` 不生效，勿再照抄：
> `PORT`、`RISK_FACTORS_FILE`、`MAX_PAGES`、`MAX_EVENTS_PER_RUN`、`DIFY_BACKEND`、`DIFY_API_KEY`、
> `EMBEDDING_BINDING_HOST`、`EMBEDDING_BINDING_API_KEY`、`EMBEDDING_MODEL`、`INNER_SIMILARITY_THRESHOLD`。
> （`CRAWLER_CONFIG` / `KNOWLEDGE_BASE_CONFIG` / `DIFY_CONFIG` 占位与 `backend/deprecated/**` 已在本轮审查中删除。）

### Windows 一键启动

项目根目录提供了启动脚本：

```cmd
REM 命令提示符（推荐，双击可直接运行）
start_all.bat
```

```powershell
# PowerShell（首次需放行脚本执行策略）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\start_all.ps1
```

### 手动分别启动

```bash
# 1. 启动 Java PMWNB 贝叶斯推理服务（端口 12313）
java -jar backend/lib/pmwnb-service.jar 12313

# 2. 启动 Java 通用预测服务（端口 12314）
java -jar backend/lib/predict-service.jar 12314

# 3. 启动 Java NB 算法服务（端口 12315，A2WNB/CAVWNB/EMAWNB/MAWNB/DIWNB 共用）
java -jar backend/lib/nb-algorithm-service.jar 12315

# 4. 启动 Python FastAPI 后端（端口 12312）
cd backend/
python -m app.main
```

访问 API 文档：http://localhost:12312/docs

## 三、数据库（PostgreSQL 16 + Docker Compose）

数据库统一使用 PostgreSQL 16，通过 Docker Compose 一键启动本地开发库（配置见项目根目录 `docker-compose.yml`）。

### 环境要求
- **Docker Desktop**（Windows）或 Docker Engine（Linux），需启用 WSL2 后端

### 启动数据库

```bash
# 项目根目录执行
docker compose up -d
```

启动后 PostgreSQL 监听 `127.0.0.1:5432`：

| 项 | 值 |
|---|---|
| 地址 | 127.0.0.1:5432 |
| 数据库 | situation_platform |
| 用户 | situation |
| 密码 | situation_dev_password |

停止服务：`docker compose down`（数据保留在数据卷中）；清空数据：`docker compose down -v`。

### 后端连接配置

后端从 `backend/app/.env` 读取 `DATABASE_URL`（未配置时 `app/db.py` 自动回落默认连接串）：

```ini
DATABASE_URL=postgresql+psycopg2://situation:situation_dev_password@127.0.0.1:5432/situation_platform
```

### 数据库迁移（Alembic）

所有表结构变更通过 Alembic 管理，禁止手工改库。在 `backend/` 目录执行：

```bash
# 创建/升级到最新结构（首次会建 14 张表并写入基础 seed 数据）
python -m alembic upgrade head

# 模型变更后生成新迁移（需数据库可连接）
python -m alembic revision --autogenerate -m "describe change"

# 回滚一个版本
python -m alembic downgrade -1

# 离线预览将要执行的 SQL（无需数据库）
python -m alembic upgrade head --sql
```

### ORM 模型与迁移脚本

- ORM 模型：`backend/app/models/`（14 张表，对应《数据库设计文档v2》2.1 ~ 2.14）
- 数据库入口：`backend/app/db.py`（engine / SessionLocal / Base）
- 迁移脚本：`backend/alembic/versions/`

## 五、中文日志乱码修复方案（Windows）

Windows 控制台默认使用 GBK 编码，Python 日志输出中文可能乱码。

### 方案 1：设置环境变量

```powershell
$env:PYTHONIOENCODING = "utf-8"
```

### 方案 2：Git Bash 启动

Git Bash 默认使用 UTF-8，直接在其中运行后端即可：

```bash
cd backend/ && python -m app.main
```

### 方案 3：Windows Terminal

使用 Windows Terminal（而非 cmd.exe），默认 UTF-8 编码。

## 六、项目目录结构（重构后）

```
security-bayes-platform/
├── frontend/                   # Vue 3 前端
│   └── src/views/              # 按业务拆分为 5 个子目录（Home / Model / Dataset / Alert / Event）
├── backend/                    # Python FastAPI 后端
│   ├── app/
│   │   ├── main.py             # 启动入口（/api/v1 15 个路由模块共 103 个端点 + legacy /api/model 8 个端点）
│   │   ├── api/                # 接口路由层
│   │   ├── services/           # 业务逻辑层
│   │   ├── algorithms/         # 贝叶斯算法核心（PMWNB）
│   │   ├── schemas/            # Pydantic 数据校验模型
│   │   └── models/             # 数据库 ORM 模型（14 张表）
│   ├── alembic/                # 数据库迁移
│   ├── lib/                    # Java 服务 jar（pmwnb / predict / nb-algorithm）
│   └── storage/                # 运行时持久化
│       ├── models/             # 训练产物：.pkl / .model 模型文件
│       └── output/             # 运行时生成的 JSON 数据
├── data/                       # 训练数据集（ARFF）
├── scripts/                    # 核心测试与工具脚本
├── logs/                       # 运行日志
└── docs/                       # 项目文档
```

> 注：原 `backend/deprecated/`（二期归档：舆情爬虫、Dify 等）已在本轮审查中整体删除，目录树不再包含。
