# 本地环境部署启动手册

## 一、前端（Vue 3 + Vite）

### 环境要求
- **Node.js** >= 18.0.0（推荐 20 LTS）
- **npm** >= 9.0.0

### 安装与启动

```bash
cd frontend/

# 安装依赖（首次或 package.json 变更后）
npm install

# 开发模式启动（默认 http://localhost:5173）
npm run dev

# 生产构建
npm run build
```

### 跨域联调配置

前端通过 axios 直连后端 `http://127.0.0.1:12312`，后端已配置 CORS 中间件允许 `localhost:5173` 跨域请求，无需额外代理配置。

如后端端口变更，修改 `frontend/src/utils/request.js` 中的 `baseURL`。

---

## 二、后端（Python FastAPI + Java PMWNB）

### 环境要求
- **Python** >= 3.10
- **Java** >= 17（用于 PMWNB 贝叶斯推理服务）
- **Windows** 10/11 或 Linux

### Python 虚拟环境搭建

```bash
cd backend/

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows Git Bash）
source venv/Scripts/activate

# 激活虚拟环境（Windows PowerShell）
.\venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt
```

### 配置环境变量

复制并编辑 `.env` 文件（位于 `backend/app/.env`），当前实际使用的配置项如下：

```ini
# 服务端口
PORT=12312

# 风险因子文件（从 backend/ 启动，路径相对于 backend/）
RISK_FACTORS_FILE=risk.txt
MAX_PAGES=10
MAX_EVENTS_PER_RUN=50
MAX_ASYNC=8
MAX_TOKENS=2048

# LLM 配置
LLM_BINDING_HOST=
LLM_BINDING_API_KEY=
LLM_MODEL=

# Dify AI 平台
DIFY_BACKEND=
DIFY_API_KEY=

# Embedding
EMBEDDING_BINDING_HOST=
EMBEDDING_BINDING_API_KEY=
EMBEDDING_MODEL=
INNER_SIMILARITY_THRESHOLD=0.7
```

### Windows 一键启动

项目根目录提供了启动脚本：

```cmd
REM 命令提示符（推荐，双击可直接运行）
start_all.bat
```

```powershell
# PowerShell（首次需放行脚本执行策略）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\start_all.ps1
```

### 手动分别启动

```bash
# 1. 启动 Java PMWNB 贝叶斯推理服务（端口 12313）
java -jar backend/lib/pmwnb-service.jar 12313

# 2. 启动 Python FastAPI 后端（端口 12312）
cd backend/
python -m app.main
```

访问 API 文档：http://localhost:12312/docs

## 三、前后端联调

| 组件 | 端口 | 地址 |
|---|---|---|
| Vue 前端 | 5173 | http://localhost:5173 |
| FastAPI 后端 | 12312 | http://localhost:12312 |
| Java PMWNB | 12313 | http://127.0.0.1:12313 |

后端 CORS 已配置允许 `http://localhost:5173` 跨域请求。

## 四、中文日志乱码修复方案（Windows）

Windows 控制台默认使用 GBK 编码，Python 日志输出中文可能乱码。

### 方案 1：设置环境变量

```powershell
$env:PYTHONIOENCODING = "utf-8"
```

### 方案 2：Git Bash 启动

Git Bash 默认使用 UTF-8，直接在其中运行后端即可：

```bash
cd backend/ && python -m app.main
```

### 方案 3：Windows Terminal

使用 Windows Terminal（而非 cmd.exe），默认 UTF-8 编码。
