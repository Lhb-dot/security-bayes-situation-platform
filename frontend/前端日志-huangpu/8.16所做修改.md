# 前端更新（8.16 SUPER_ADMIN 平台总览落地页与用户管理权限修正）

> 日期：2026-08-16
> 范围：`frontend/` SUPER_ADMIN 登录落地页（`/overview`）三大板块补齐、用户管理权限与角色显示修正、平台总览布局美化
> 基线：《V3.0需求分析(1).md》6.5.2（权限矩阵）/ 7.0（管理员平台驾驶舱）；后端 `user_service.py` / `user_routes.py` 权限规则对齐

---

## 一、本次工作概要

1. **SUPER_ADMIN 登录落地页补齐三大板块**：`/overview`（`AdminOverviewView.vue`）在原有顶部状态条、全局指标、场景运行状态卡、图表、事件流基础上，新增「平台待办/审批区」「平台规模与组织概览」「快捷入口/工作台导航」。
2. **用户管理权限修正（对齐后端）**：系统管理员可见全部账号、可创建场景管理员与场景用户；场景管理员仅可见本场景下的场景管理员与场景用户（含自己）、只能在自己场景内创建场景用户。
3. **角色名称全站统一**：系统管理员 / 场景管理员 / 场景用户三级叫法贯穿用户管理页、顶栏、登录页，消除此前「管理员/用户」的歧义。
4. **平台总览整体美化与布局修正**：统一卡片阴影/悬停动效/区块标题锚点，场景运行状态卡拉长消除与事件流之间的空白。

---

## 二、改动明细

### 新增：`src/types/security.ts`

- 新增 `PlatformUserStats` 接口：平台账号总数、平台管理员 / 场景管理员 / 场景用户数量、禁用账号数、按场景的用户分布。

### 修改：`src/services/mockApi.ts`

- 新增 `getPlatformUserStats()`：仅 SUPER_ADMIN 可调用，按账号角色、状态、绑定场景聚合统计。
- `getUserList()` 权限修正（对齐后端 `UserService.get_list`）：
  - SUPER_ADMIN：返回全部账号（系统管理员 + 场景管理员 + 场景用户）；
  - SCENARIO_ADMIN：返回自己场景内的场景管理员与场景用户（含自己）。
- `createUser()` 创建规则修正（对齐后端 `UserService.create`）：
  - SUPER_ADMIN：可创建 SCENARIO_ADMIN 或 SCENARIO_USER（均必须绑定场景）；
  - SCENARIO_ADMIN：只能在自己场景内创建 SCENARIO_USER；
  - 新增「场景管理员/场景用户必须绑定场景」校验。

### 修改：`src/stores/userStore.ts`

- 新增 `platformStats` 状态与 `fetchPlatformStats()` action，供平台总览使用。

### 修改：`src/views/Admin/AdminOverviewView.vue`

**新增板块：**

- **平台待办/审批区**：六张待办卡片（待审核发布 / 训练失败 / 训练中 / 待处置高危 / 禁用账号 / 预留场景），数据来自 modelStore 模型状态、风险事件状态、平台账号统计、场景接入状态；点击卡片跳转对应模块，全部为 0 时显示「暂无待办，平台运行平稳」。
- **平台规模与组织概览**：账号总数 / 平台管理员 / 场景管理员 / 场景用户 / 禁用账号统计 + 「各场景用户分布」横向柱状图（点击柱子进入对应场景大屏）+ 各场景管理员名单。
- **快捷入口/工作台导航**：场景中心、模型训练、模型中心、数据集中心、用户管理、推理记录、报告中心、系统设置八个入口卡片。

**数据链路：** 页面刷新（含 30 秒轮询）新增 `modelStore.fetchModelVersions()`、`userStore.fetchUsers()`、`userStore.fetchPlatformStats()`。

**布局与美化：**

- `admin-main` 两列改为等高拉伸，场景卡网格占满剩余高度，消除卡片与事件流之间的空白；
- hero 增加「欢迎回来，{用户名}」问候语；
- 页面背景增加蓝紫光晕，各区块统一卡片阴影、淡入上移动画、悬停上浮微动效；
- 区块标题统一渐变竖条视觉锚点。

### 修改：`src/components/admin/ScenarioStatusCard.vue`

- 卡片 `height: 100%` 随网格行高拉伸；指标区与「近24h事件趋势」迷你图改为弹性伸展（`flex: 1`），拉长后空间被内容均匀吸收。

### 修改：`src/views/Model/UserManagement.vue`

- 角色徽章拆分三级并配不同颜色：系统管理员（琥珀）/ 场景管理员（紫）/ 场景用户（蓝），不再笼统显示「管理员」；
- 页面头部「当前登录」显示完整角色名；
- 创建账号弹窗：标题改为「创建账号」；系统管理员可下拉选择「场景管理员 / 场景用户」，场景管理员固定「场景用户」；
- 场景管理员创建按钮文案调整为「创建场景用户」。

### 修改：`src/App.vue` / `src/views/Login.vue`

- 顶栏头像角色、登录成功提示、登录页演示账号按钮的角色名称统一为 系统管理员 / 场景管理员 / 场景用户。
