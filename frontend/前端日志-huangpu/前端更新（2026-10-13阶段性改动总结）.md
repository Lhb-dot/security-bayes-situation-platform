# 前端更新（2026-10-13 阶段性改动总结）

> 日期：2026-10-13（北京时间）  
> 依据：当天提交 `bf66fc1` 的前端差异；只记录前端及直接配套的账号清单生成脚本。  
> 范围：登录联调、数据集中心、场景数据画像、风险研判及接口类型。10 月 14 日的管理员驾驶舱重构另见同目录当日日志。

## 一、解决的问题与改动

| 原有问题 | 具体改动 | 结果 |
| --- | --- | --- |
| 开发联调时需要反复手输不同场景、不同角色的账号 | 新增独立的 `QuickLoginPanel.vue`，按场景和角色筛选账号，支持直接选择超级管理员；登录页仅接入该组件 | 切换测试身份更方便，原登录表单和登录卡布局保持原有位置 |
| 切换账号后，场景编码与数字 ID 的旧缓存可能属于上一个账号 | 在 `scenarioApi.ts` 增加缓存清理和缺失时重取逻辑；`userStore.ts` 清理会话时同步清空该缓存 | 新账号按自己的可见场景重新解析，避免误报“场景不存在” |
| 数据集上传和“手工修改字段创建版本”混在一个弹窗中，交互与实际文件上传流程不一致 | 上传弹窗只保留新数据集文件上传；选择 ARFF/CSV 文件并填写编码、名称、场景和标签字段，由后端解析文件结构 | 上传路径更明确，减少手填字段、文件路径等容易出错的输入 |
| 数据集追加后的反馈无法清楚说明版本结果 | “追加样本”统一改称“追加数据”；根据接口返回的版本号区分原地并入和自动新建版本，并显示更新后的样本条数 | 用户能直接知道本次迭代采用了哪种版本处理方式 |
| 版本管理弹窗较窄，版本表和迭代记录较多时容易挤出屏幕 | 加宽并居中弹窗，限制高度；版本表和迭代记录分别在区域内滚动；迭代记录保留独立审计视角 | 版本信息更易核对，长列表不会无限撑高弹窗 |
| 数据集上传、追加文件的原生选择控件样式不统一 | 改为云上传图标按钮触发隐藏的文件控件，并显示所选文件名；重新选择同一文件也能触发变更 | 两处文件选择交互一致，状态更清晰 |
| “同源文件去重”的文案容易让人以为不同编码形态也会合并 | 同步修正首页、场景接口类型和舰面数据画像的说明，明确只对内容完全相同的重复注册文件去重 | 展示口径与实际统计规则一致；“同源组”相关标签改为“内容分组”等更准确的名称 |
| 风险研判样本区在没有可读取样本时缺少明确反馈 | 增加空状态文案“该数据集没有可读取的样本” | 用户能区分加载中与确实无样本 |

## 二、主要实现

### 1. 开发阶段快捷登录

- `components/dev/QuickLoginPanel.vue` 独立实现账号列表、场景与角色筛选、加载禁用和失败提示。点击账号仍调用 `userStore.login()`，使用原有登录接口和按角色落地的路由逻辑，没有绕过鉴权。
- `components/dev/devAccounts.generated.ts` 为开发账号清单，由 `scripts/gen_quick_login_accounts.py` 根据数据库中的账号、角色和场景生成；没有在日志中抄录账号口令。
- `Login.vue` 接入面板，面板绝对定位于登录卡右侧，不改变原登录表单的居中布局。`QuickLoginPanel.spec.ts` 新增了账号筛选、登录跳转和错误提示等用例。
- **适用范围：开发联调。** 当日代码中的 `QUICK_LOGIN_ENABLED` 为 `true`，生成清单包含供浏览器使用的测试凭据；正式对外部署前应关闭或移除这一入口及清单。

### 2. 数据集中心

- `DatasetCenter.vue` 移除了前端手工编辑字段后创建版本的入口，保留文件上传和“追加数据”两条清晰路径。追加时是否原地并入、是否生成新版本，由后端迭代策略决定。
- 上传和追加都改用图标选文件，并展示文件名。上传表单保留场景、数据集编码、名称和标签字段的必要输入。
- 版本管理弹窗扩大到适合查看表格的宽度，并按视口限制高度；版本表与迭代记录各自滚动，迭代记录标题与内容区分开。

### 3. 场景与首页统计口径

- `scenarioApi.ts` 的场景 ID 缓存随会话失效，缺少编码映射时按当前账号重新请求场景列表。
- `dashboardApi.ts`、`scenarioApi.ts`、`situationApi.ts`、`AdminOverviewPage.vue`、`ProfileFlightdeck.vue` 和 `ProfilePower.vue` 对齐“内容重复文件去重”的字段说明与展示文案。舰面画像中的冗余率、分组表和去重收益采用同一口径。
- `security.ts` 的算法定义注释补充新接入算法名称，保持类型说明与可用算法范围一致。

### 4. 风险研判回归用例

- `RiskInference.vue` 补充无可读样本时的空状态提示。
- `RiskInference.spec.ts` 依据页面已有的自动选择行为，调整了场景、数据集、模型、字段、样本分页和换账号请求交错的用例。本节属于用例更新，并发控制本身沿用既有实现。
