### 二、数据范围隔离（需求 6.8，P0）

所有数据接口强制按当前登录账号过滤，前端隐藏按钮不替代权限控制：

- `getRiskEvents` / `getInferenceRecords`：普通用户强制只返回本人数据，管理员返回全平台或指定用户
- `getGlobalOverview` / `getScenarioDetail` / `getSituationData` / `getScenarioList`：普通用户只统计本人事件
- 未接入场景（航母甲板）不虚构数据

### 三、数据集版本管理（需求 2.3，P0）

- `DatasetCenter.vue`：管理员「上传数据集」（指定场景 + 字段校验 + 必含分类标签）、版本管理弹窗（停用/删除，被引用只能停用不能物理删除）
- mockApi：`uploadDataset` / `createDatasetVersion` / `disableDatasetVersion` / `deleteDatasetVersion`，样本数严格用需求 2.1 数字（7556/23897/2000）

### 四、算法注册与训练（需求 6.6 / 6.3.1，P0）

- mockApi 注册五种算法：`A2WNB / MAWNB / EMAWNB / DIWNB / PMWNB`，每种带公开训练参数定义（默认值/类型/范围/校验）
- `RiskAnalysis.vue`：仅管理员可训练；选择场景 → 数据集版本 → 算法 → 动态参数表单 → 训练生成 **DRAFT** 模型版本（需求 6.7.2），展示 Accuracy/Recall/Precision/Specificity/F1/G-mean（需求 6.4）

### 五、模型生命周期与发布（需求 6.7，P0）

- 模型状态机：`TRAINING → DRAFT → PUBLISHED → OFFLINE`（含 `FAILED`）
- `ModelCenter.vue`：管理员审核发布、下线、重新发布、设置「场景＋数据集」默认推荐模型；普通用户仅见已发布模型（需求 6.7.5）
- 默认模型下线时自动取消默认（需求 6.7.4.5）

### 六、单条样本推理闭环（需求 6.3.2 / 6.2，P0）

- `RiskInference.vue`：选择场景 → 数据集 → 展示该范围全部已发布模型（含评估指标）→ 自动选中默认推荐模型（无默认提示手动选择，无已发布提示"暂无可用模型"）→ 按模型绑定数据集生成固定字段表单 → 推理
- `executeInference`：风险类结果按场景阈值计算风险等级，**生成统一 RiskEvent（16 字段，需求 5.2）并关联推理记录**；正常类只保存推理记录
- 枚举字段按数据集值域渲染下拉框并校验（需求 3.1.5，KDD/UNSW/PowerGrid 值域已录入）

### 七、推理记录（需求 6.2，P0）

- `InferenceRecords.vue` 新增：普通用户仅本人记录，管理员可查全部并按用户/场景筛选（需求 6.8.4）

### 八、风险阈值按场景（需求 5.4.1，P0）

- `Settings.vue`：网络/电力分别维护 `medium_threshold / high_threshold`，范围 [0,1]、high>medium、保存即实时生效；每次修改记录变更日志（操作人/场景/时间/前后值）；航母甲板仅预留

### 九、P1 功能

- `ReportCenter.vue`：生成态势报告（普通用户仅本人数据，管理员可选全平台/指定用户）并支持导出 Markdown
- `ModelCenter.vue`：模型版本对比（指标对比并高亮最优，普通用户仅能比较已发布模型）

### 关键类型变更

- `RiskEvent` 补齐 `inference_record_id / created_by_user_id / dataset_version / algorithm_id`（需求 5.2）
- 新增 `UserAccount / AlgorithmDefinition / AlgorithmParamDef / InferenceRecord / ThresholdConfig / ThresholdChangeLog / EvaluationMetrics / DatasetVersion`
- `ModelStatus` 生命周期状态机；`Dataset` 补 `dataset_version / uploaded_by / uploaded_at / enabled / referenced`

## 2026-08-04（补充）：前端职责内缺口补齐

需求评审后确认：前端只负责前端，后端鉴权/持久化不在本次范围。以下三项属**纯前端职责**，已补齐：

### 一、数据集"修改→新版本"入口（需求 2.3.3，P0）

之前 `createDatasetVersion` 仅存在于数据层，页面无入口。本次补齐：

| 文件 | 说明 |
|:-----|:------|
| `src/views/Model/DatasetCenter.vue` | 版本管理弹窗新增「修改字段 → 创建新版本」按钮；上传/新版本弹窗共用（模式切换），新版本模式下编码/名称/场景/格式继承并只读；提交后调用 `createDatasetVersion` 创建 v2，旧版本保留，历史模型/推理记录/风险事件继续可追溯 |

### 二、推理接口层枚举/字段强制校验（需求 3.1.5 / 3.1.3 / 3.1.6，P0）

之前仅推理表单渲染了枚举下拉框，接口层可绕过。本次在 `executeInference` 内新增 `validateInputFeatures`：

- **必填**：所有输入特征字段不得为空
- **数值类型**：float/int 字段必须为数值
- **枚举值域**：按数据集定义的值域校验（KDD `protocol_type`/`service`/`flag` 等，UNSW `Label`，PowerGrid `Component`/`SystemName`/`IssueType` 等）
- **字段名**：只接受数据集正式字段名，不得按列序号互换（需求 3.1.6）

绕过前端直接调接口同样会被拦截。

### 三、首页大屏接口登录校验（需求 1.1.1，P0）

`getDashboardSnapshot / getAlerts / getAlertById` 三个接口补充 `requireLogin()`，接口级强制未登录不可访问，不再只依赖路由守卫。
