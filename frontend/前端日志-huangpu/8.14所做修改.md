## 二、改动明细

### 新增：`src/utils/scenarioAlgorithms.ts`

纯函数、确定性计算、无 `any` / `ts-ignore`，输入字段与 mockApi 数据集正式字段一致（大小写兼容变体）：

| 场景 | 函数 | 说明 |
|:-----|:-----|:-----|
| 网络安全 | `zScoreAnomaly` | 留一法滑动窗口 Z-score 突变检测（需求 8.1） |
| 网络安全 | `networkPortDeviation` | 端口偏离度评分 0-100（相对均匀基线偏离倍数，≥2 倍标记异常） |
| 电力系统 | `powerDeviceHealth` | 设备健康分 0-100（越限率 70% + 平均风险评分 30%） |
| 电力系统 | `powerRiskScore` | 加权风险评分（包丢失 30% + 电压 25% + 电流 20% + 温度 15% + 频率 10%，偏差基准取事件集合基线均值） |
| 地质风险 | `geoSusceptibilityScore` | 地形因子标准化叠加的 0-100 易发性指数（坡度/TWI/SPI/高程 + 距断层/河流/道路距离） |
| 地质风险 | `geoRegionRanking` | 区域按易发性评分排序 |
| 航母甲板 | `collisionRiskScore` | 碰撞风险评分 0-100（最小间距 60% + 接近率 40%） |
| 航母甲板 | `trajectoryDeviationScore` | 轨迹偏差评分（双机方向角 / 相对角 / 间距标准差相对经验基线） |

### 四看板接入（第 8 节）

- **NetworkDashboard**：新增「流量偏离度预判（轻量算法）」面板——端口偏离度横向柱状图（点击可带端口跳转推理预填）+ 异常端口数 / Z-score 突变窗口数摘要。
- **PowerDashboard**：设备健康排行改为 0-100 健康分（替代纯计数）；新增「风险评分模型」面板展示最近事件综合评分与电压/电流/温度/频率偏差、遥测包丢失。
- **GeologicalDashboard**：新增「区域易发性评分 TOP」面板（事件按 0-100 易发性指数排序）。
- **FlightdeckDashboard**：新增「碰撞风险评估（轻量算法）」面板——碰撞风险分（最小间距+接近率）、轨迹偏差分与各标准差明细。

### 权限对齐（6.5.2）

- `src/router/index.ts`：`/overview` meta 增加 `requiresAdmin: true, hiddenForUser: true`。
- `src/App.vue`：顶部导航「全局总览」增加 `requiresAdmin / hiddenForUser`，普通用户不再看到该入口。

### 甲板热点图（7.4.1）

- `src/components/Deck/DeckHeatMap.vue`：占位底图升级为内联 SVG 甲板示意；`fault_position_x/y` 红点定位、缩放换算、悬停 tooltip、点击跳详情逻辑全部不变。

### 登录/登出同步修复（8.13 遗留交互问题）

- `src/views/Login.vue`：登录改走 `userStore.login()`，与路由守卫同源，登录后无需刷新即进入落地页。
- `src/App.vue`：当前用户改为 `computed(() => userStore.currentUser)`，登出改走 `userStore.logout()`，登出后无需刷新即回到登录页；删除 `syncCurrentUser` 手动同步逻辑。
