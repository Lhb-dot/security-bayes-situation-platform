本次将「AI 模型训练」页从纯 mock 数据改为**从数据库渲染**（场景 / 数据集 / 算法全部来自 `/api/v1`），并接入**真实 PMWNB Java 训练**（weka 算法）；同时修复了全站多处 UI 问题。涉及前端与后端联调改造。

### 一、AI 训练页数据库化（需求 6.6 / 6.7，P0）

场景、数据集、算法不再来自 mockApi，而是从数据库接口渲染；训练不再跑假数据。

| 文件 | 操作 | 说明 |
|:-----|:-----|:------|
| `src/api/trainingApi.js` | 新增 | 真实接口封装：`getScenarios / getDatasets / getAlgorithms / trainModel`（POST `/api/v1/model-versions/train`） |
| `src/views/Model/RiskAnalysis.vue` | 重写 | 场景按已注册场景渲染；数据集按所选场景的数据库数据集渲染；算法按注册算法渲染；参数表单按算法 `param_schema` 动态生成 |
| `src/services/mockApi.ts` | 修改 | 用户记录补充 `backend_id`，登录 session 改存后端数字 ID（与后端 `X-User-Id` 对齐） |

**训练链路（前端视角）**：

```
选择场景 → 选择该场景下数据集 → 选择算法（五种，参数表单按 param_schema 动态生成）
  → POST /api/v1/model-versions/train
      ├─ PMWNB：真实调用 Java（weka）服务训练，返回真实指标（source=java_pmwnb）
      └─ A2WNB / MAWNB / EMAWNB / DIWNB：算法组未交付，mock 占位指标（source=mock，前端标注"模拟数据"）
  → 训练成功生成 DRAFT 模型版本，展示 Accuracy/Recall/Precision/Specificity/F1/G-mean
```

- 指标卡片：缺失字段（如真实 PMWNB 无 specificity/g_mean）显示 `—`，不虚构数据
- 真实训练结果带 `java_pmwnb` 标记、mock 结果带 `mock` 标记，前端据此提示来源
- 校验联动：数据集必须属于所选场景（跨场景选择后端返回 400），仅管理员可训练
