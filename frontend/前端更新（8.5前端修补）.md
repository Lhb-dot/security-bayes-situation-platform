# 前端更新记录

## 2026-08-05：用户分级 v2 审查后的前端修补

本次依据《用户分级v2.md》复查 8 月 4 日实现，修补普通用户数据越权、数据集版本未真正绑定、推理字段版本错配及报告统计范围错误等问题。

### 验证结果

```bash
npm run build
# ✓ vue-tsc -b
# ✓ vite build
```

### 修补内容

| 类别 | 文件 | 修补说明 |
|:-----|:-----|:---------|
| 旧版全平台页面隔离 | `src/router/index.ts`、`src/App.vue` | 普通用户不再显示旧版“首页大屏”和“告警中心”；直接访问 `/dashboard`、`/alerts` 或告警详情会跳转至 `/overview`。旧版页面使用全平台演示数据，不可作为普通用户的个人态势入口。 |
| 用户列表权限 | `src/services/mockApi.ts`、`InferenceRecords.vue`、`UserManagement.vue` | `getUserList` 改为仅管理员可调用；普通用户页面不再请求用户列表，避免泄露平台账号信息。 |
| 指定训练版本 | `RiskAnalysis.vue`、`mockApi.ts` | 训练页新增“训练数据集版本”选择框，只显示启用版本；`trainModel` 按 `dataset_id + dataset_version` 精确查询并校验版本，不再忽略前端选择的版本。 |
| 推理字段版本一致性 | `RiskInference.vue`、`mockApi.ts` | `getDatasetFields` 支持显式传入版本；推理表单按模型的 `dataset_id + dataset_version` 获取输入字段，防止数据集升级后使用错误字段推理。 |
| 数据集字段校验 | `mockApi.ts` | 上传与创建新版本时校验字段非空、字段名唯一、字段类型合法，且必须且只能有一个“分类标签”字段。 |
| 指定用户报告 | `mockApi.ts` | 管理员生成“指定用户”报告时，风险事件统计会按 `target_user_id` 过滤，不再误用全平台事件。 |
| 航母甲板未接入提示 | `SituationAnalysis.vue` | 态势分析不再把航母甲板场景并入统计与图表，并在页面说明中明确该场景暂未接入数据集。 |
| 算法显示名称 | `RiskInference.vue` | 推理页挂载时加载算法注册表，模型卡片可显示算法名称而非只有算法编码。 |

### 仍需后端接入的事项

上述权限与数据版本规则目前在 `src/services/mockApi.ts` 中模拟，刷新页面会重置业务数据。正式交付前，仍需由后端实现并持久化：

- 会话鉴权与服务端数据范围过滤；
- 数据集文件、字段结构与版本管理；
- 模型训练、评估、发布及版本存储；
- 推理记录、RiskEvent、阈值变更日志和报告的持久化。
