# 基于 Transformer 的网络安全态势感知与威胁可视化平台

这是一个使用 `Vue 3 + TypeScript + Vite` 构建的前端可视化项目，面向“网络安全态势感知、威胁分析、攻击链展示、告警研判”场景。当前版本以前端展示为主，后端接口已预留，暂时通过本地随机数据进行驱动，方便先完成页面设计、交互和大屏演示。

## 当前功能

- 首页态势感知大屏
- 当前威胁总数、高危事件数、AI 研判准确率、平均响应时间
- 攻击趋势折线图，支持鼠标悬浮查看详细信息
- 攻击类型分布图
- Top 攻击源 IP
- Top 受攻击主机
- 攻击协议分布
- 防护联动效率展示
- 中国 / 世界地图切换
- 攻击轨迹动画展示
- 全屏作战大屏模式
- 告警详情页
- AI 分析结果、原始日志、风险等级、处置建议、攻击时间线
- 指标卡点击下钻，查看近 30 天趋势

## 技术栈

- Vue 3
- TypeScript
- Vite
- 自定义 SVG / CSS 可视化交互

## 项目启动

### 1. 安装依赖

```bash
npm install
```

如果在 Windows 中文目录下执行 `npm install` 很慢或异常，可以先映射一个短盘符再执行：

```bat
subst X: "D:\000大学学习\大二下\软件工程导论\ai检测攻击可视化"
X:
npm install
```

### 2. 启动开发环境

```bash
npm run dev
```

### 3. 构建生产版本

```bash
npm run build
```

## 项目结构

```text
src/
  components/        主要页面与可视化组件
  services/          mock 数据接口层，后续可替换为真实后端请求
  types/             类型定义
  App.vue            应用总入口
  main.ts            挂载入口
  style.css          全局样式

public/
  maps/              中国与世界 SVG 地图底图
```

## 后续如何接后端

当前项目的前端页面已经和数据结构解耦。后续只需要替换 `src/services/mockApi.ts` 中的这些方法即可：

- `getDashboardSnapshot()`
- `getAlerts()`
- `getAlertById()`
- `refreshMockData()`

你可以把它们替换成：

- `axios`
- `fetch`
- Spring Boot 接口
- Flask / FastAPI 接口

页面层无需大改。

## 地图说明

当前版本使用本地 SVG 底图叠加攻击轨迹动画，不依赖百度地图或高德地图 `AK`，更适合课程展示和离线答辩。

如果后续需要接入真实地图服务，也可以继续扩展为：

- 百度地图
- 高德地图
- ECharts 地图
- 自定义 GeoJSON 地图
